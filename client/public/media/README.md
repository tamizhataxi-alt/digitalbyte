# Site media

Each file in this folder is mapped once in `src/data/siteMedia.ts` (case-study art is per project slug only; service detail heroes use `serviceMedia` per slug).

## Optional hero video

Place a short, muted loop at `hero-loop.mp4` (software / product engineering themed). The hero will auto-detect it; otherwise the poster image uses a subtle Ken Burns animation.
